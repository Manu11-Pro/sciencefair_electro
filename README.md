# SpaceRF

This is Project SpaceRF, a portable ionospheric solar flare detector. Instead of relying on expensive, high-power mini-computers or satellite dishes, I engineered a low-noise analog frontend circuit board for under 500 rupees that turns a standard smartphone into a live space weather receiver.
My 0.62-meter telescoping antenna captures military carrier signals at 18.20 kilohertz reflecting off the edge of space, using a loose 1.5-meter wire on the floor as an electrical mirror. When a solar flare erupts, its X-rays instantly alter the atmosphere's conductivity. My circuit boosts these tiny voltage changes and passes them through a TRRS splitter, allowing my phone to run real-time audio spectrum analysis via Spectroid. As you can see right here on the live waterfall graph, the 18.20 kilohertz line is actively tracking the state of our upper atmosphere."
